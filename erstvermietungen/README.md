# Erstvermietungen von Genossenschaften im Raum Zürich (CSV)

Archiv der Erstvermietungen gemeinnütziger Bauträgerinnen, zusammengestellt von
[Genossenschaftsscout](https://www.genossenschaftsscout.ch/erstvermietungen-zuerich). Eine Zeile pro Projekt, neueste Bewerbung zuerst.

| Spalte | Bedeutung |
|---|---|
| `projekt`, `traegerin`, `ort`, `art` | Projekt, Bauträgerin, Ort/Quartier, Art (Neubau, Ersatzneubau …) |
| `wohnungen`, `zimmer_von`, `zimmer_bis` | Anzahl Wohnungen und Zimmerspanne laut Ausschreibung |
| `mieten` | Mieten laut Ausschreibung (Text, wie veröffentlicht) |
| `bewerbung_start`, `bewerbung_ende` | Bewerbungsfenster (ISO-Datum oder Monat), `bewerbung` als Text |
| `bezug`, `status` | Bezug und Stand der Vermietung |
| `seite` | Projektseite mit allen Details |
